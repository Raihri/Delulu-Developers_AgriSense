AGRISENSE TIER 0 GAP ANALYSIS
Audit date: 2026-07-25

AUDIT BASIS

This report compares:
1. Tier 0 on page 3 of docs/Agentic_AI_Hackathon_Final_Question.pdf
2. The target and checkpoint claims in docs/ARCHITECTURE.md
3. The current backend, frontend, curated data, migrations and tests

The PDF requires one complete path from a short conversation to a grounded,
explained and costed season plan for one farm. All eight capabilities must work
end to end.

EXECUTIVE VERDICT

AgriSense is not Tier-0 complete yet.

It is a strong, fail-closed foundation with working conversational intake, real
weather retrieval, curated Supabase tables, financial formulas, limited season
events, RAG retrieval, persistence and a visible trace interface.

It still does not produce:
- at least three same-season crops ranked using actual weather values
- one farmer-chosen crop
- a complete dated land-preparation-to-harvest calendar
- a costed plan in the normal conversation-to-plan flow
- per-recommendation explanations grounded in retrieved facts
- raw-enough trace evidence to reproduce every displayed number

Strict status: 1 PASS, 6 PARTIAL, 1 MISSING.

TIER 0 STATUS

1. CONVERSATIONAL INTAKE - PASS

Implemented:
- Gemini structured extraction
- controlled enums and evidence quotes
- progressive clarification
- live browser location and Google Maps
- compact Supabase context across turns

Still needed:

DECISIVE BLOCKERS

P0 - NO SEASON HAS THREE COMPARABLE CROPS

The current catalog cannot satisfy the crop-ranking requirement. The shortest
safe path is to freeze the demo to Rabi and curate one additional Rabi crop,
such as wheat, across calendar, soil, water, yield, cost, fertilizer and
operation tables.

P0 - WEATHER IS FETCHED BUT NOT USED AS WEATHER

backend/agent/controller.py fetches the daily series, but passes only a Boolean
weather_available flag to backend/tools/recommend.py. Pass the daily values,
calculate sourced risk/suitability, and attach exact evidence.

P0 - THERE IS NO RANKING

Every crop returns not_ranked_until_all_limiting_factors_are_available. Complete
a narrow, reviewed same-season data slice and retain the fail-closed gate for
unsupported cases.

P0 - THE SEASON PLAN IS INCOMPLETE

Add a structured crop-operation table and one complete chosen-crop template
covering land preparation, sowing, fertilizer, irrigation, weed, pest and
harvest events with reviewed relative timing.

P0 - THE CORE FLOW IS NOT COSTED

Ask for finance-assumption consent in the conversation, pass the farmer budget,
allow edits, recompute in the backend, and return finance for the selected crop.

P0 - RAG DOES NOT GROUND THE PLAN

Keep exact numbers in structured tables. Use RAG for cited explanatory guidance,
attach chunk IDs to advice, apply a relevance threshold, and trace retrieval.

P0 - TRACE OUTPUT IS TOO SUMMARIZED

Store/display the exact bounded values used, tool type, formula/source version,
duration, status and a trace ID on every output number.

SHORTEST TIER 0 COMPLETION ORDER

1. Freeze demo to Rabi and one golden farm.
2. Curate one additional Rabi crop so three crops are comparable.
3. Feed actual weather values into suitability and risk.
4. Integrate non-paddy water balance with explicit inputs.
5. Return a deterministic top-three ranking.
6. Ask the farmer to choose a crop.
7. Build one complete dated operation template.
8. Carry finance consent, budget and editable assumptions into the plan.
9. Retrieve and attach RAG guidance.
10. Make every output number traceable to exact values/formula.
11. Correct README, architecture status and demo runbook.

TIER 0 ACCEPTANCE FLOW

The judge must be able to:
1. Start with a vague message.
2. Answer only missing-field questions.
3. See a real farm-location forecast.
4. See three same-season crops ranked.
5. Inspect suitability, water need, risk and profit for each.
6. Choose one crop.
7. Receive a complete dated plan.
8. Inspect costs, yield, revenue, profit, ROI and break-even.
9. Read explanations naming farm inputs, weather and sources.
10. Reproduce every number from visible tool values or formula inputs.

Until this passes, call AgriSense a partial Tier-0 prototype.
